# RL Map Designer

Browser-based 3D Rocket League arena designer with one-click export to Rocket League via BakkesMod.

## Features

- Full arena customization (width, length, height, corner radius, walls, ceiling)
- 6 arena presets (Standard RL, Narrow, Low Ceiling, Octagon, 1D, Open Field)
- 7 goal presets (Standard, Impossible, Triple, Double, Wall Goals, Giant, Ceiling)
- Place boost pads, goals, spawn points, ball spawn anywhere with full 6DOF
- Undo/Redo (Ctrl+Z / Ctrl+Y) — full command history
- Auto-layout: 34 official RL boost pads + spawns at exact coordinates
- One-click export straight into Rocket League (requires UDK + BakkesMod)
- Steam Workshop upload via SteamCMD
- Export JSON (Unreal Units) and T3D (paste into UDK) as fallback

## Quick Start

```bash
# 1. First-time setup (one-time, ~3 min for UDK compile)
python3 scripts/setup.py

# 2. Start the export server (terminal 1)
python3 scripts/server.py

# 3. Start the web server (terminal 2)
python3 -m http.server 8080

# 4. Open the designer
# http://localhost:8080
```

## Requirements

| Component | Required | Purpose |
|---|---|---|
| Python 3 | Yes | Server + setup scripts |
| UDK 2013-07 | Yes (for RL export) | Builds the .udk map file |
| Rocket League | Yes (for RL export) | Target game |
| BakkesMod | Optional | Auto-loads map via RCON |
| SteamCMD | Optional | Workshop upload |
| websocket-client | Optional | BakkesMod RCON (`pip install websocket-client`) |

### UDK Installation

UDK (Unreal Development Kit 2013) is the only tool that can build Rocket League maps.
It must be installed and pointed to by `scripts/settings.json`.

Download: search "UDK_RL_Setup community script" on the RL modding Discord,
or download UDK 2013-07 from the Unreal Engine archive.

## Export Pipeline

```
[Web App]
    ↓ POST /export (arena JSON)
[server.py :8081]
    ↓ Write arena_build.json
    ↓ UDK.exe -run=RLMapDesignerCommandlet
    ↓ Copy RLMapDesigner_Output.udk → Labs_Underpass_P.upk
    ↓ BakkesMod RCON: load_freeplay
[Rocket League loads map]
```

## Data Model

Arena JSON format (also used for save/load):

```json
{
  "version": 1,
  "arena": {
    "preset": "standard",
    "fw": 96, "fl": 120, "wh": 24,
    "cornerR": 8,
    "walls": true,
    "ceiling": true
  },
  "objects": [
    {
      "id": 1,
      "type": "goal",
      "paletteType": "goal_blue",
      "position": [0, 0, -60],
      "rotation": [0, 0, 0],
      "scale": [1, 1, 1],
      "properties": { "team": 0, "width": 21, "height": 8, "depth": 5 }
    }
  ],
  "meta": { "title": "", "description": "", "previewPath": "" }
}
```

Scale: **1 Three.js unit ≈ 85.3 Unreal Units** (`SCALE_UU = 85.3`)

## Goal Presets

| Preset | Description |
|---|---|
| Standard | Classic RL goals (w=21, h=8) |
| Impossible | Tiny goals (w=2, h=1.5) — viral challenge map style |
| Triple | 3 goals per end — Lethamyr Triple Goal |
| Double | 2 angled goals per end (V-shape) |
| Wall Goals | Goals on side walls, rotated inward |
| Giant | Near full-wall goals |
| Ceiling Goals | Goals on ceiling, facing downward |

## Server API

```
GET  /status   → { udk, rl_found, bakkesmod, steamcmd, ... }
POST /export   → arena JSON → { ok, error?, warning? }
POST /publish  → arena JSON (with meta.title) → { ok, publishedfileid?, error? }
```

## Troubleshooting

**"Server not running"** — start `python3 scripts/server.py` in a separate terminal.

**"UDK not found"** — run `python3 scripts/setup.py` and enter your UDK path.

**"BakkesMod RCON refused"** — make sure Rocket League is running and BakkesMod is loaded.
The map was still copied; restart RL Freeplay to load it.

**Map not loading in RL** — ensure RL is using the correct game mode.
The map replaces Labs_Underpass (Soccar Labs). Load it via Freeplay > Labs > Underpass,
or use BakkesMod console: `load_freeplay`

**Restore after accidental close** — press Ctrl+L or click Load and choose your .json.
Auto-save runs on every edit (stored in localStorage).
